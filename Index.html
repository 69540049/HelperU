Thai Exam Camera Assistant

ถ่ายโจทย์ → อ่านคำถาม → ค้นคำตอบจากเอกสารเรียน

① ตั้งค่าแหล่งอ้างอิงและ AI

เลือกไฟล์ “เนื้อหาสอบภาษาไทย.pdf” เพื่อให้ระบบใช้เอกสารนี้เป็นแหล่งอ้างอิง หากเป็น PDF สแกน ระบบจะ OCR หน้าเอกสารในเบราว์เซอร์ (ใช้เวลาตามจำนวนหน้า)
ยังไม่ได้โหลดเอกสารอ้างอิง
คีย์จะอยู่ในหน่วยความจำของหน้านี้เท่านั้น ไม่บันทึกลงไฟล์หรือ Local Storage แต่การเรียก API จากเว็บโดยตรงมีความเสี่ยง ควรใช้คีย์ชั่วคราวและไม่แชร์ไฟล์นี้พร้อมคีย์

② ถ่ายภาพคำถามด้วยกล้องมือถือ

กด “เปิดกล้อง” เพื่อเริ่มถ่ายภาพโจทย์
เคล็ดลับ: ถ่ายให้เห็นโจทย์และตัวเลือกครบ ภาพตรง ไม่เอียง และมีแสงเพียงพอ

③ คำตอบจากเอกสารอ้างอิง

ผลการวิเคราะห์จะแสดงที่นี่ พร้อมเหตุผลและตำแหน่งเนื้อหาอ้างอิงเมื่อค้นพบ

วิธีใช้งาน

1. โหลด PDF เนื้อหาสอบเพื่อสร้างคลังอ้างอิง
2. ใส่ API Key สำหรับให้ AI อ่านภาพและวิเคราะห์โจทย์
3. เปิดกล้องหรือเลือกรูปคำถาม
4. ตรวจข้อความ OCR แล้วกดวิเคราะห์
5. อ่านคำตอบ เหตุผล และหัวข้อ/หน้าที่อ้างอิงจากเอกสาร
ระบบนี้เป็นผู้ช่วยทบทวนบทเรียน ไม่รับประกันคำตอบทุกข้อ หากเอกสารไม่มีข้อมูลรองรับ ระบบจะระบุว่า “ไม่พบหลักฐานในเอกสาร” แทนการเดาคำตอบ
