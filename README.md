# Thai Exam Camera Assistant V4.0 — Review Edition

อัปเดตจาก V3 โดยเพิ่มคลังเฉลยและระบบทบทวนข้อสอบรายวิชา 89520864 ภาคเรียน 1/2569 จำนวน 75 ข้อ (ข้อ 4–78)

## ฟังก์ชันใหม่
- คลังเฉลยครบ 75 ข้อ แบ่ง 4 หมวด พร้อมคำอธิบาย
- ฝึกทำข้อสอบแบบสุ่มเป็นรอบ และตรวจคำตอบทันที
- กรองทุกข้อ / ข้อที่ตอบผิด / ข้อที่ยังไม่เคยทบทวน / ข้อควรตรวจสอบ
- แก้ไขเฉลยได้เมื่อได้รับเฉลยทางการจากอาจารย์
- บันทึกโน้ตส่วนตัวต่อข้อ
- บันทึกสถิติการทบทวนและผลแต่ละรอบใน localStorage ของอุปกรณ์
- ส่งออกข้อมูลทบทวนเป็น JSON เพื่อสำรอง/ย้ายอุปกรณ์
- คงฟังก์ชันเดิม: กล้อง, OCR, อ่าน PDF และค้นหาเอกสารแบบ local ฟรี

## วิธีติดตั้ง GitHub Pages
อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์นี้ไปยัง root ของ repository แล้วเปิด GitHub Pages ผ่าน HTTPS

## หมายเหตุเฉลย
เฉลยตั้งต้นเป็นฉบับวิเคราะห์จากการทบทวน ไม่ใช่เฉลยทางการ ข้อที่มีเครื่องหมายควรตรวจสอบถูกตั้งสถานะไว้ ผู้ใช้สามารถเปลี่ยนตัวเลือกเฉลยและบันทึกโน้ตได้ ข้อมูลทบทวนอยู่ใน localStorage ของ browser/device นั้น ๆ ควรส่งออก JSON เพื่อสำรองข้อมูล
